# Herramienta de Auditoría de Seguridad Automatizada

Proyecto de la asignatura **Seguridad y Auditoría de Sistemas** — Universidad Mariano Gálvez de Guatemala, Sede Zacapa.

Herramienta de auditoría que escanea el **Sistema de Administración y Gestión (SAG)** y el **portal de acceso** de la Cooperativa de Ahorro y Crédito Nuevo Amanecer, R.L., identifica y prioriza brechas de seguridad conforme al **OWASP Top 10**, y genera un informe accionable.
